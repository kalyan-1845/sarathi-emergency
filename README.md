**Sarathi** is a smart emergency location-sharing and intelligent routing system. This project was published as a research paper in **IJARSCT (International Journal of Advanced Research in Science, Communication and Technology)** in 2026.

📄 **DOI**: [10.48175/IJARSCT-32733](https://doi.org/10.48175/IJARSCT-32733)

---

## 🚀 Features

- 📍 **Real-Time GPS Tracking**: Share your live location with emergency contacts instantly
- 🗺️ **Intelligent Routing**: Optimized pathfinding for ambulances and emergency responders
- 🚑 **Emergency SOS**: One-tap SOS alert with automatic location broadcast
- 📞 **Multi-Contact Alerts**: Notify multiple emergency contacts simultaneously
- 🏥 **Nearest Facility Finder**: Locate the closest hospitals, police stations, and fire departments
- 🔄 **Live Location Updates**: Continuous GPS updates for real-time tracking

## 🏗️ Tech Stack

| Component | Technology |
|---|---|
| **Frontend** | TypeScript, React |
| **Mapping** | Google Maps API / Leaflet |
| **Routing** | Dijkstra / A* Pathfinding |
| **GPS** | Geolocation API |
| **Backend** | Node.js |
